# Design system

## Principes

- premium sans folklore cliché ;
- photographie large et immersive ;
- hiérarchie typographique forte ;
- interactions simples sur smartphone ;
- ludique dans la mécanique, adulte dans l’exécution.

## Tokens

| Token | Valeur | Usage |
|---|---|---|
| `--bg` | `#fbf7ef` | ivoire / fond |
| `--card` | `#ffffff` | cartes |
| `--ink` | `#1d211d` | texte principal |
| `--green` | `#174f3a` | nature / CTA principal |
| `--orange` | `#d96832` | aventure / énergie |
| `--yellow` | `#f2c75c` | accent chaleureux |

## Formes

- cards : 20–28 px de rayon ;
- boutons : 14 px ;
- navigation mobile : dock flottant 20 px ;
- zones tactiles : ≥ 44 px lorsque possible.

## Accessibilité

- contraste renforcé sur CTA ;
- états textuels en plus de la couleur ;
- géolocalisation toujours facultative ;
- animations non essentielles au fonctionnement ;
- roulette avec résultat lisible même sans animation.
